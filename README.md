# Luporini & Mancini Advocacia - Landing Page

Landing page institucional para o escritório de advocacia Luporini & Mancini.

## ⚖️ Sobre o Projeto
Landing page moderna, responsiva e sofisticada projetada para transmitir autoridade, excelência jurídica e confiança aos clientes.

## 🚀 Tecnologias
- HTML5 Semântico
- CSS3 Moderno (Design System com variáveis CSS, tipografia refinada e animações suaves)
- JavaScript Vanilla para interatividade

## Imagem de fundo da home
- Fotografia da estátua da Justiça: [fonte no Unsplash](https://images.unsplash.com/photo-1589829545856-d10d557cf95f).
- Versões locais em preto e branco, no formato WebP, com larguras de 1200 e 2400 pixels.
- O navegador seleciona a versão adequada à tela, e o degradê da home mantém o contraste dos textos sobre a fotografia.
